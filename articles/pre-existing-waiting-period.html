หน้าหลัก เกี่ยวกับเรา แบบประกัน ค้นหาแบบประกัน ข่าวสารและบทความ แนะนำอาชีพ ปรึกษาฟรี

ประกันสุขภาพ

โรคเดิม (Pre-existing Condition) และระยะรอคอยประกันสุขภาพ ต่างกันอย่างไร?

ทำความเข้าใจการแจ้งประวัติสุขภาพ เงื่อนไขที่มักมีผลต่อการคุ้มครอง และวิธีเตรียมเอกสารให้ครบก่อนทำกรมธรรม์

คำตอบโดยสรุป

โรคเดิม (Pre-existing Condition) คือโรค อาการ หรือภาวะสุขภาพที่มีอยู่ก่อนวันที่ความคุ้มครองเริ่มต้น โดยการพิจารณาว่าเข้าข่ายหรือได้รับความคุ้มครองหรือไม่ ต้องเป็นไปตามข้อมูลสุขภาพ การพิจารณารับประกัน และเงื่อนไขของกรมธรรม์

ส่วน ระยะรอคอย (Waiting Period) คือช่วงเวลาหลังกรมธรรม์เริ่มมีผล ซึ่งโรคหรือการรักษาบางประเภทอาจยังไม่ได้รับความคุ้มครอง แม้ผู้เอาประกันจะไม่เคยมีโรคนั้นมาก่อนก็ตาม

ดังนั้น “โรคเดิม” กับ “ระยะรอคอย” ไม่ใช่เรื่องเดียวกัน และการผ่านระยะรอคอยไม่ได้หมายความว่าโรคเดิมทุกโรคจะได้รับความคุ้มครองโดยอัตโนมัติ


โรคเดิม หรือ Pre-existing Condition คืออะไร?

ในบริบทของประกันสุขภาพ โรคเดิมหมายถึงโรค อาการ ความผิดปกติ หรือภาวะสุขภาพที่มีอยู่ก่อนวันที่กรมธรรม์หรือสัญญาเพิ่มเติมมีผลบังคับ

การพิจารณาไม่ได้ดูเพียงว่าผู้สมัคร “เคยได้รับการวินิจฉัยว่าเป็นโรคหรือไม่” แต่บริษัทอาจพิจารณาข้อมูลสุขภาพที่เกี่ยวข้อง เช่น

  1. ประวัติการรักษา
  2. อาการที่เคยเกิดขึ้น
  3. ผลตรวจสุขภาพหรือผลตรวจทางห้องปฏิบัติการ
  4. การใช้ยาอย่างต่อเนื่อง
  5. การผ่าตัดหรือการรักษาในอดีต
  6. ระยะเวลาที่ติดตามอาการ
  7. ภาวะแทรกซ้อนที่เกี่ยวข้อง

รายละเอียดที่ใช้พิจารณาอาจแตกต่างกันตามแบบประกันและหลักเกณฑ์ของบริษัทประกัน

มีโรคเดิมแล้ว ยังทำประกันสุขภาพได้ไหม?

มีโอกาสทำได้ แต่ไม่ได้หมายความว่าจะได้รับความคุ้มครองทุกกรณี

เมื่อมีประวัติสุขภาพ บริษัทประกันจะพิจารณารับประกันเป็นรายบุคคล ผลการพิจารณาอาจแตกต่างกัน เช่น

  1. รับประกันตามเงื่อนไขปกติ
  2. รับประกันโดยมีเงื่อนไขเพิ่มเติม
  3. ยกเว้นความคุ้มครองเฉพาะโรคหรือภาวะบางอย่าง
  4. ขอข้อมูลหรือผลตรวจเพิ่มเติมก่อนพิจารณา
  5. เลื่อนการพิจารณา
  6. ไม่รับประกันในบางกรณี

ดังนั้น การมีโรคประจำตัว ไม่ควรตีความทันทีว่าทำประกันไม่ได้ แต่ควรให้ข้อมูลสุขภาพครบถ้วนเพื่อให้บริษัทประกันเป็นผู้พิจารณา

ทำไมต้องแจ้งประวัติสุขภาพตามความเป็นจริง?

การแถลงข้อมูลสุขภาพเป็นส่วนสำคัญของขั้นตอนสมัครประกัน

หากใบคำขอถามถึงโรค อาการ การตรวจ หรือประวัติการรักษา ควรตอบตามข้อเท็จจริงและขอบเขตคำถามอย่างครบถ้วน

ตัวอย่างข้อมูลที่ควรเตรียมไว้ ได้แก่

  1. ชื่อโรคหรืออาการที่เคยเป็น
  2. โรงพยาบาลที่รักษา
  3. วันที่หรือช่วงเวลาที่รักษา
  4. ยาที่ใช้อยู่
  5. ผลตรวจล่าสุด
  6. ประวัติการผ่าตัด
  7. ผลการติดตามอาการจากแพทย์

ข้อมูลที่ครบจะช่วยให้การพิจารณารับประกันชัดเจนขึ้น และลดปัญหาเมื่อมีการเรียกร้องผลประโยชน์ในอนาคต

ระยะรอคอยประกันสุขภาพคืออะไร?

ระยะรอคอย (Waiting Period) คือช่วงเวลาหลังจากความคุ้มครองเริ่มต้นที่โรคหรือการรักษาบางประเภทอาจยังไม่ได้รับความคุ้มครอง

ระยะรอคอยถูกกำหนดไว้ในเงื่อนไขกรมธรรม์หรือสัญญาเพิ่มเติม และอาจแตกต่างกันตามประเภทความคุ้มครองและแบบประกัน

ตัวอย่างเช่น โรคบางกลุ่มอาจมีระยะรอคอยเฉพาะก่อนที่จะเริ่มได้รับความคุ้มครอง

ผู้ที่ต้องการศึกษาประเด็นนี้โดยละเอียดสามารถอ่านต่อได้ที่

ระยะรอคอย 120 วัน คืออะไร? โรคใดบ้างที่ต้องรอก่อนเคลมประกันสุขภาพ

โรคเดิมกับระยะรอคอย ต่างกันอย่างไร?

ประเด็นโรคเดิมระยะรอคอย
เกี่ยวข้องกับช่วงเวลาใดก่อนความคุ้มครองเริ่มต้นหลังความคุ้มครองเริ่มต้น
เกี่ยวกับประวัติสุขภาพเดิมหรือไม่ใช่ไม่จำเป็น
มีผลต่อการรับประกันหรือไม่อาจมีโดยทั่วไปเป็นเงื่อนไขของความคุ้มครอง
ผ่านช่วงเวลาแล้วคุ้มครองอัตโนมัติหรือไม่ไม่จำเป็นต้องดูเงื่อนไขของโรคนั้นและกรมธรรม์
ต้องพิจารณาเป็นรายบุคคลหรือไม่มักเกี่ยวข้องกับการพิจารณารับประกันส่วนใหญ่ดูตามเงื่อนไขกรมธรรม์

สิ่งสำคัญที่สุดคือ อย่านำสองเรื่องนี้มาปนกัน

ผ่านระยะรอคอยแล้ว โรคเดิมจะได้รับความคุ้มครองหรือไม่?

ไม่สามารถสรุปได้ว่าคุ้มครองโดยอัตโนมัติ

นี่เป็นจุดที่ผู้ทำประกันสุขภาพมักเข้าใจผิด

ตัวอย่างเช่น หากกรมธรรม์กำหนดระยะรอคอยของโรคบางประเภทไว้ การพ้นระยะรอคอยหมายถึงเงื่อนไขด้าน “เวลา” ของโรคนั้นผ่านแล้ว

แต่หากโรคนั้นมีอยู่ก่อนทำประกัน หรืออยู่ภายใต้ข้อยกเว้นที่บริษัทกำหนดไว้ ก็ต้องพิจารณาตามเงื่อนไขดังกล่าวแยกต่างหาก

Waiting Period จึงไม่ใช่เครื่องมือที่ทำให้ Pre-existing Condition กลายเป็นโรคที่ได้รับความคุ้มครองโดยอัตโนมัติ

ถ้าไม่เคยตรวจพบโรคมาก่อน แต่ตรวจพบหลังทำประกันล่ะ?

กรณีนี้ไม่ควรตัดสินจาก “วันที่ตรวจพบโรค” เพียงอย่างเดียว

เมื่อมีการเคลม บริษัทประกันอาจพิจารณาข้อมูลตามเงื่อนไขของกรมธรรม์ รวมถึงประวัติสุขภาพและข้อมูลทางการแพทย์ที่เกี่ยวข้อง

จึงไม่ควรสรุปว่า

“ตรวจเจอหลังทำประกัน = ต้องเคลมได้แน่นอน”

หรือ

“ตรวจเจอหลังทำประกัน = ต้องเป็นโรคเดิมแน่นอน”

ต้องพิจารณาข้อเท็จจริงและเงื่อนไขของกรมธรรม์เป็นกรณีไป

ก่อนทำประกันสุขภาพ ควรเตรียมอะไรบ้าง?

หากมีประวัติการรักษา การเตรียมข้อมูลตั้งแต่ต้นช่วยให้การสมัครง่ายขึ้น

1. รวบรวมประวัติสุขภาพที่สำคัญ

ทบทวนว่าที่ผ่านมาเคย

  1. เข้าโรงพยาบาล
  2. ผ่าตัด
  3. ตรวจพบความผิดปกติ
  4. รับยาต่อเนื่อง
  5. ติดตามอาการกับแพทย์
  6. ตรวจสุขภาพแล้วมีค่าผิดปกติหรือไม่

2. เตรียมเอกสารที่มีอยู่

เช่น

  1. ใบรับรองแพทย์
  2. ผลตรวจสุขภาพ
  3. ผลเลือด
  4. ผล X-ray / CT / MRI ที่เกี่ยวข้อง
  5. รายการยา
  6. สรุปประวัติการรักษา

ไม่จำเป็นต้องเตรียมทุกอย่างในทุกกรณี แต่หากบริษัทต้องการข้อมูลเพิ่มเติม การมีเอกสารพร้อมจะช่วยให้ดำเนินการได้สะดวกขึ้น

3. อ่านคำถามสุขภาพทีละข้อ

ไม่ควรตอบจากความเข้าใจว่าตัวเอง “สุขภาพดี” หรือ “ไม่มีโรคร้ายแรง”

ควรตอบตามสิ่งที่ใบคำขอถามจริง

4. ตรวจเงื่อนไขหลังบริษัทอนุมัติ

หากบริษัทรับประกันแล้ว ควรตรวจสอบว่า

  1. รับประกันแบบปกติหรือไม่
  2. มีข้อยกเว้นเพิ่มเติมหรือไม่
  3. มีเงื่อนไขเฉพาะหรือไม่
  4. ระยะรอคอยมีอะไรบ้าง

ก่อนยืนยันรับกรมธรรม์

ทำไมควรทำประกันสุขภาพตั้งแต่ยังไม่มีปัญหาสุขภาพ?

ประกันสุขภาพเป็นเครื่องมือสำหรับจัดการความเสี่ยงของค่าใช้จ่ายในอนาคต ไม่ใช่เครื่องมือสำหรับซื้อหลังจากทราบแล้วว่าจะต้องเข้ารับการรักษา

การพิจารณาทำประกันในช่วงที่สุขภาพยังแข็งแรงจึงมีข้อได้เปรียบ เพราะประวัติสุขภาพเป็นหนึ่งในข้อมูลที่อาจมีผลต่อการพิจารณารับประกัน

อย่างไรก็ตาม การเลือกประกันไม่ควรดูเฉพาะว่าสมัครผ่านหรือไม่ แต่ควรพิจารณาทั้ง

  1. วงเงินค่ารักษา
  2. ค่าห้อง
  3. ความคุ้มครองผู้ป่วยในและผู้ป่วยนอก
  4. Deductible
  5. Copayment
  6. ระยะรอคอย
  7. ข้อยกเว้น
  8. เบี้ยระยะยาว
  9. สวัสดิการเดิมที่มีอยู่

หากยังไม่เข้าใจพื้นฐาน สามารถเริ่มจาก

ประกันสุขภาพคืออะไร? เข้าใจหน้าที่ก่อนเลือกวงเงินและแผนคุ้มครอง

คำถามที่พบบ่อย (FAQ)

โรคเดิมกับโรคประจำตัวเหมือนกันไหม?

ไม่จำเป็นต้องเหมือนกันทุกกรณี คำว่าโรคประจำตัวเป็นคำที่ใช้ทั่วไป ขณะที่การพิจารณา Pre-existing Condition ในประกันต้องอ้างอิงนิยาม เงื่อนไขกรมธรรม์ และข้อมูลทางการแพทย์ที่เกี่ยวข้อง

มีโรคประจำตัวแล้วทำประกันสุขภาพได้ไหม?

มีโอกาสทำได้ การพิจารณาขึ้นอยู่กับโรค ความรุนแรง ประวัติการรักษา ผลตรวจ และหลักเกณฑ์รับประกันของบริษัท

ถ้าไม่แจ้งโรคเดิม บริษัทจะรู้หรือไม่?

สิ่งสำคัญไม่ใช่ว่าบริษัทจะทราบหรือไม่ แต่คือผู้สมัครควรตอบคำถามสุขภาพตามความเป็นจริงและครบถ้วนตามที่ใบคำขอสอบถาม เพื่อให้การพิจารณารับประกันเป็นไปอย่างถูกต้อง

ผ่านระยะรอคอยแล้ว โรคเดิมจะเคลมได้ไหม?

ไม่จำเป็น เพราะโรคเดิมและระยะรอคอยเป็นคนละเงื่อนไข ต้องดูผลการพิจารณารับประกัน ข้อยกเว้น และรายละเอียดของกรมธรรม์ร่วมกัน

ระยะรอคอยเริ่มนับเมื่อไร?

โดยทั่วไปนับจากวันที่ความคุ้มครองตามกรมธรรม์หรือสัญญาเพิ่มเติมเริ่มมีผล ทั้งนี้ต้องตรวจสอบรายละเอียดในกรมธรรม์แต่ละฉบับ

ถ้าเคยผ่าตัดมาหลายปีแล้ว ต้องแจ้งหรือไม่?

ให้พิจารณาจากคำถามสุขภาพในใบคำขอ หากคำถามครอบคลุมประวัติการผ่าตัดหรือการรักษาดังกล่าว ควรแจ้งตามข้อเท็จจริง


สรุป

ก่อนทำประกันสุขภาพควรแยกให้ออกระหว่าง “โรคเดิม” กับ “ระยะรอคอย”

โรคเดิมเกี่ยวข้องกับสุขภาพและเหตุการณ์ที่เกิดขึ้นก่อนเริ่มความคุ้มครอง และอาจมีผลต่อการพิจารณารับประกัน

ส่วนระยะรอคอยคือช่วงเวลาหลังเริ่มความคุ้มครองที่โรคหรือการรักษาบางประเภทอาจยังไม่สามารถใช้สิทธิได้

ดังนั้น การผ่านระยะรอคอย ไม่ได้หมายความว่าโรคเดิมจะได้รับความคุ้มครองโดยอัตโนมัติ

วิธีที่ดีที่สุดก่อนสมัครคือ แจ้งข้อมูลสุขภาพตามความจริง อ่านเงื่อนไขให้เข้าใจ และตรวจผลการพิจารณารับประกันก่อนรับกรมธรรม์

  1. ประกันสุขภาพคืออะไร? เข้าใจหน้าที่ก่อนเลือกวงเงินและแผนคุ้มครอง
  2. ระยะรอคอย 120 วัน คืออะไร? โรคใดบ้างที่ต้องรอก่อนเคลมประกันสุขภาพ
  3. มีโรคประจำตัวแล้ว ยังทำประกันชีวิตได้หรือไม่?
  4. ทำไม “ประกันสุขภาพ” ควรพิจารณาซื้อคู่กับ “ประกันชีวิตตลอดชีพ” มากกว่าผูกไว้กับประกันประเภทอื่น?


หากคุณมีประวัติสุขภาพหรือมีกรมธรรม์เดิมอยู่แล้ว สามารถนำข้อมูลความคุ้มครองและประวัติที่เกี่ยวข้องมาช่วยวิเคราะห์ก่อนสมัคร เพื่อให้เข้าใจว่าแผนประกันใหม่ควรเติมช่องว่างด้านใด และมีประเด็นใดที่ควรตรวจสอบก่อนยื่นใบคำขอ
